# 敘事腳本 — 第一章：失聲的港灣

## 0:00–0:30｜開場（自動，3 框，可跳過）

畫面先說話：浮標在浪裡搖、沒有鐘聲；村民面向海；遠處觀測站閃一下光。

1. 阿海伯（望海，懷疑）：「浮標還在動——聲音卻不見了。」
2. 沈芮（急切）：「整個港的回聲正在被抽走。訊號源，是舊潮汐觀測站。」
3. 沈芮（專注）：「你去。到村口先『觀測』，跟著回聲走。」

HUD 提示（非對話，2 秒淡出）：`C／觀測鍵：回聲觀測`

## 0:30–1:15｜村口觀測（第一次判讀）

觀測模式中可調查三個線索（各 1 框，調查即記錄）：

- 潮痕：「沙上的潮痕全都退向低處海灣——這是自然的方向。」
- 電波刮痕：「斷續的電波刮痕，一路往上坡去。這訊號不自然。」
- 無聲波紋：「水面有波紋，卻沒有聲音。回聲被什麼吃掉了。」

蒐集 ≥2 條後，村口路標可做出選擇——

**選擇**「跟著哪個方向走？」
- 「上坡・電波刮痕」（正解）→ 沈芮（無線電）：「對，往上坡。牠出手前會先『吸氣』——盯著天線看。」
- 「沿岸・自然潮痕」（誤）→ 教學遭遇：
  - 進場：「一隻潮翼被突來的寂靜嚇得炸了毛，朝你衝過來！」
  - 結束：「潮翼安靜下來，朝上坡的方向叫了一聲。」（自動補正路線資訊）

## 1:15–2:00｜潮霧古道（20–30 秒過場）

- 地標・傾倒的中繼天線（調查）：「三十年前的中繼天線，鏽出了洞。今天，它在微微發燙。」
- 補給（互動即得）：「巡山員的補給箱：青草膏 ×1。」
- 可選觀測位（站上後自動觀測）：「強波之前，長鬚會先發紅、往後繃——記住這個前兆。」
- 異常加劇（踩線觸發）：「腳下的碎石在震。聲音，一層一層變少了。」

## 2:00–2:30｜觀測站進場（4 框，含 FX，可跳過）

1.（燈序亮）「設備自己醒了。指示燈一盞、一盞亮起。」
2.（聲音抽離）「浪聲、風聲、你的腳步聲……逐層消失。」
3.（電波聚集）「電波在房間中央絞成一團——有東西被裹在裡面。」
4.（磁殼仔現身，驚訝→擔憂）「磁殼仔！牠不是奪走聲音的兇手——牠被三十年的殘留訊號纏住了。」

## 2:30–4:00｜頭目戰文字

前兆（每次行動前必出）：
- 強波：「長鬚發紅，向後繃緊——強波要來了！」
- 衝撞：「殼一縮，腳蹬地——要衝撞！」
- 靜電：「天線亂顫，灑出靜電！」

回饋：
- 防禦成功：「穩流護住了你們，傷害被壓了下來。」
- 防禦錯時：「防得不是時候，波還是掃了進來。」
- 干擾成功：「逆頻打中充能！牠的訊號亂了——就是現在！」
- 干擾落空：「逆頻沒對上節拍，只激起一圈雜訊。」
- 共鳴過早：「共鳴被雜訊蓋過。等牠訊號亂掉的瞬間再試。」
- 階段轉換：「殼縫裡透出光——訊號更急了。牠在怕。」
- 共鳴成功：「共鳴器咬住了頻率。」→「纏住牠的舊訊號，一圈、一圈剝落。」

## 4:00–5:00｜結局（6 框內）＋伏筆

回到廣場（色溫轉暖、環境聲回歸）：

1.（鐘聲 FX）「——鐺。浮標的鐘聲，回來了。」
2. 阿海伯（微笑）：「聽見沒？海又開口了。」
3. 沈芮（釋然）：「觀測站安靜了。牠只是想把耳朵還給我們。」
4. 系統：「取得『穩定回聲』。進度已寫入觀測手冊。」（自動存檔）

**章節卡**：`第一章：失聲的港灣　完成`

**伏筆（黑幕，2 框，10 秒內）**：
1. 「當晚，觀測器又輕輕響了一聲。」
2. 「同樣的訊號——來自遠方的島。這一次，它有節拍。」（切黑）

→ 選單：`繼續探索　／　返回標題`

- 小滿（戰後）：「鐘響了！你聽、你聽！」
