# 視覺稽核報告（Visual Audit）

稽核日期：2026-08-27
稽核方式：實際啟動遊戲（`--tour`）擷取九類畫面，逐項檢查。
Before 截圖：`docs/screenshots/before/`　After 截圖：`docs/screenshots/after/`

評級：🔴 不可接受（阻擋出貨）／🟠 明顯低於商業水準／🟡 可用但粗糙

---

## 1. 開始畫面（before/title.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🔴 純色深綠背景毫無場景感；三隻怪獸圖直接平鋪；無標題設計、無氛圍、無視覺焦點層次 |
| 問題原因 | 背景用單一 ColorRect；無標題畫、無前中後景概念 |
| 改善方式 | 產生 320×180 分層標題背景（海面色帶、遠山霧、港村剪影、桅杆與浮標、動態霧），標題字獨立排版，選單改用 UI 系統樣式 |
| 優先順序 | P1（玩家第一眼） |
| 驗收標準 | 背景可辨識「山海交界的聚落」；有前中後三層；選單有焦點樣式 |

## 2. 小鎮（before/world_town.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🔴 大片單一草色空地；建築是兩塊「磚紋矩形」無屋頂/門窗層次；樹木單一複製；無陰影、無生活物件、無前景遮蔽；一眼是工程測試圖 |
| 問題原因 | 單層 TileMap、11 個 tile、無 deco/overhead 層；地圖設計只考慮碰撞不考慮敘事 |
| 改善方式 | 重製為「霧港村」：三層 TileMap（地面/物件/頂層）、鏽鐵皮與紅磚屋頂差異、石牆、水道、電線桿、浮標、旗幟、炊煙、前景植被；地面加不規則紋理變化 |
| 優先順序 | P1 |
| 驗收標準 | 稽核清單 12 項視覺細節全數出現；無 3×3 以上的重複純色區 |

## 3. 野外道路（before/world_route.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🔴 一條垂直直線走廊；高草是均勻方陣；無高低差、無支線、無地標 |
| 問題原因 | 地圖 12×14 過小、無設計語言 |
| 改善方式 | 重製為「潮霧古道」：主路＋支線、石階與崖層暗示高低差、觀景點、倒木封路、隱藏獎勵、異常事件點、霧粒子 |
| 優先順序 | P1 |
| 驗收標準 | 至少一條支線與一個探索獎勵；玩家能說出「這條路通往哪裡」 |

## 4. 室內（before/world_house.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🔴 空房間＋一張紅地墊；無家具、無光源方向、無角色性格 |
| 問題原因 | 室內只有 3 種 tile（牆/地板/墊） |
| 改善方式 | 重製兩個室內：玩家住所（床、桌、櫃、生活痕跡、暖色溫）與回聲觀測所（儀器、書架、海圖、冷暖混合光） |
| 優先順序 | P2 |
| 驗收標準 | 不看文字能分辨兩個室內的用途差異 |

## 5. NPC 對話 | 6. 隨機遭遇 | 7. 戰鬥（before/battle.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🔴 戰鬥＝灰綠兩色背景＋兩張圖＋文字框；無進場、無受擊回饋、無腳下接地陰影；遭遇無演出直接切場景 |
| 問題原因 | 戰鬥場景只做了功能層 |
| 改善方式 | 依遭遇地生成分層戰鬥背景；進場滑入、Idle 呼吸、攻擊前傾、命中閃白＋位移＋粒子＋震動、HP 平滑、捕捉動畫、勝利結算；遭遇加音效與轉場 |
| 優先順序 | P1 |
| 驗收標準 | 第九節清單 10 項全數實裝且不破壞像素一致性 |

## 8. 選單／隊伍／背包（before/pause_menu.png）

| 項目 | 內容 |
|---|---|
| 現況問題 | 🟠 深藍面板是「Debug Label 清單」；無圖示、無行樣式、選取只靠 `>` 字元；佔畫面過半 |
| 問題原因 | 無 Design System |
| 改善方式 | 建立 `docs/ui-system.md` 設計系統（觀測手冊風：米白紙面＋深藍綠框＋珊瑚橘焦點），行元件含 HP 條與圖示，四態（普通/焦點/按下/停用） |
| 優先順序 | P2 |
| 驗收標準 | 所有 UI 共用同一 Theme；無 Godot 預設樣式 |

## 9. 行動版觸控介面

| 項目 | 內容 |
|---|---|
| 現況問題 | 🟠 半透明色塊方向鍵＋純色圓形 A/B（違反「純色圓形」禁令）；風格與世界無關 |
| 問題原因 | 佔位素材 |
| 改善方式 | 重繪為觀測儀器風按鍵（描邊、內陰影、銅圈刻度感），維持自動偵測與行為 |
| 優先順序 | P3 |
| 驗收標準 | 按鍵與 UI 同色盤；按下有視覺回饋 |

## 全域問題

| 項目 | 內容 |
|---|---|
| 字型 | 🟠 Noto Sans TC 抗鋸齒渲染與像素美術密度衝突 → 改用 Fusion Pixel 12px（OFL，繁中），關閉 AA 與 subpixel |
| 色盤 | 🔴 各素材色彩互不相關、高飽和原色 → 建立 40 色全域色盤 `docs/palette.md` |
| 角色 | 🔴 玩家/NPC 是換色火柴人（2 幀、鏡射腳）→ 16×24、每方向 4 幀、剪影差異化 |
| 怪獸 | 🔴 32×32 幾何圖形加眼睛 → 64×64 前/背面、剪影生態化、Idle/受擊幀 |
| 世界觀 | 🔴 泛用「小鎮＋森林＋可愛怪獸」→ 重寫為《潮霧群島》（見 `docs/world-bible.md`） |
