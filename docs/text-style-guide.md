# 文字風格指南

## 原則

1. 自然、精準的繁體中文，台灣語感；禁機翻腔與 AI 套話。
2. 先讓玩家「看到」異常，文字只補畫面說不了的部分；畫面能表達的不重複。
3. 一個對話框一個重點；每頁 ≤2 行（12px 字、每行約 22 字）。
4. 教學動作導向：「盯著天線看」而不是「本作採用前兆判讀系統」。
5. 選項文字必須可預期結果（「上坡・電波刮痕」而非「走這邊」）。
6. 戰鬥訊息短、有節奏、動詞開頭；前兆句一律以「——」收尾製造緊張。
7. 專有名詞單框最多一個；不讓 NPC 朗讀設定。
8. 禁：空泛中二台詞、被選中的救世主、光明黑暗、長篇世界觀開場。

## 密度上限（硬性）

```text
開場對話           ≤4 框（實作 3）
單次 NPC 對話      ≤3 框
教學提示           ≤2 行（HUD，非對話框）
頭目戰前演出       ≤4 框
結尾               ≤6 框（實作 4＋章節卡＋2 框伏筆）
必要文字總量        300–500 中文字
```

## 語氣速查

- 沈芮：句號多、逗號少。命令與判斷，不解釋兩次。
- 阿海伯：口語、比喻、「——」拖音；帶笑意。
- 小滿：短句疊字，驚嘆號，一次只講一件事。
- 旁白：具象名詞＋強動詞（絞、剝落、咬住）；不用形容詞堆疊。

## 校對清單

錯字／裁切／標點全形／「妳/你」統一用「你」／數字半形／
專名統一：迴靈、回聲、共鳴器、觀測手冊、潮汐觀測站、穩定回聲。
