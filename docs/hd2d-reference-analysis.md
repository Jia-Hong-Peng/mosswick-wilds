## 歸納出的可驗收視覺規則（本作採用）

1. **攝影機**：正交、俯角 30–40°、**無 yaw 旋轉**（參考圖全部近正面）；角色永遠銳利、位於中景。
2. **立體感的第一來源是「台地＋階梯」**，不是 shader：每個主要場景至少兩個高度層與一段可行走階梯。
3. **五層構圖**：前景遮擋（預模糊）→ 操作平面（銳利）→ 中景 → 背景（低對比）→ 遠背景（霧色帶）。
4. **光**：1 盞方向光長影＋2–3 盞暖色點光（窗/燈）對比冷環境色；God Ray 用預烘焙面片。
5. **移軸**：單通道帶狀柔焦（上下各一帶、4 tap）＋暗角＋遠景預先降對比；操作區永不失焦。
6. **texel 密度統一**：場景貼圖與角色同為 16px/格密度；角色描邊＋亮半階製造分離。
7. **水**：深色底＋捲動噪聲高光＋岸邊泡沫立牌；不做 SSR/即時反射。
8. **接地**：角色 blob 陰影＋物件底部烘焙 AO 暗帶。
9. **色彩**：環境低飽和統一色調，重點色只給敘事物（旗、燈、異常訊號）。
10. **UI 永遠銳利**（CanvasLayer 疊加，不受場景分級影響）。

## Compatibility/WebGL2 降級對照

| 桌面級效果 | Web 替代（本作實作） |
|---|---|
| 真實 DoF/散景 | 前景預模糊 Sprite＋螢幕單通道帶狀柔焦（4 tap）＋暗角 |
| Volumetric Fog/FogVolume | 分層霧面片（不同速度漂移）＋Environment 深度霧＋遠景低對比貼圖 |
| SSAO/SSIL | 貼圖烘焙 AO（側面壓暗、底緣暗帶、頂點色） |
| SSR 水反射 | 雙層捲動噪聲＋假 Fresnel＋高光貼圖＋暗色倒影帶 |
| SDFGI/GI | WorldEnvironment 環境色＋手放假光（發光漸層面片） |
| 即時多光源陰影 | 方向光陰影 ×1（High）／Blob only（Low）；點光 2–3 盞無陰影 |
| 體積 God Ray | 預烘焙光束貼圖面片 |
| 動態模糊/高成本後處理 | 不使用 |

## Web High / Web Low 差異（詳見 web-hd2d-performance.md）

High：方向光陰影、帶狀柔焦、全數霧片與粒子、水面雙層噪聲。
Low：關陰影（blob）、關柔焦（保留暗角）、霧片減半、粒子減半、水面單層。
降級只削裝飾；角色/道路/線索/前兆可讀性兩檔一致。
