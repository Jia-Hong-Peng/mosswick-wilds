# Vertical Slice 稽核（v0.2 → DEMO 重製前）

稽核日期：2026-08-27　基準畫面：`docs/screenshots/v0.2-baseline/`
結論：v0.2 已有完成度不錯的**系統與美術底盤**，但作為 DEMO 它**沒有關卡**——
沒有目標、沒有節奏、沒有高潮、沒有結局。玩家走進世界後不知道要做什麼。

優先級定義：P0 流程阻塞／P1 核心玩法與節奏／P2 文字美術動畫 UI／P3 裝飾

---

## 1. 開始畫面
- 現況問題：畫面合格，但按下開始後沒有「事件」承接，直接落入自由探索。
- 玩家感受：「遊戲要我做什麼？」
- 根本原因：無開場演出、無任務結構。
- 改善方式：New Game 直入霧港村廣場開場（30 秒內：浮標無聲＋觀測站閃光＋兩句對話交付目標）。
- 優先級：P0　驗收：0:30 內玩家知道異常、目的地、為何是自己。

## 2. 開場／目標
- 現況問題：完全沒有。芮姊的委託藏在可錯過的 NPC 對話裡。
- 玩家感受：漫遊、無方向。
- 根本原因：敘事只放在可選對話。
- 改善方式：自動觸發的開場（≤3 框）＋螢幕提示觀測鍵。
- 優先級：P0　驗收：不與任何 NPC 對話也能知道要去觀測站。

## 3. 核心玩法（觀測）
- 現況問題：「回聲觀測員」只是設定文字；玩法仍是走路→踩草→隨機戰。
- 玩家感受：身分與操作脫節。
- 根本原因：無觀測機制。
- 改善方式：新增回聲觀測模式（去彩度＋線索顯形＋環境音收窄）；本關使用兩次：
  村口路徑判讀（選錯→30 秒教學遭遇，不懲罰進度）、頭目前兆判讀。
- 優先級：P1　驗收：觀測含蒐集 2–3 線索＋一次有後果的選擇＋戰鬥可用資訊。

## 4. 隨機遭遇
- 現況問題：古道 14% 踩草隨機戰，與 DEMO 節奏衝突（重複、無意義）。
- 玩家感受：被打斷。
- 根本原因：沿用怪獸 RPG 慣性。
- 改善方式：DEMO 動線全移除隨機遇敵；唯一小戰鬥改為「選錯路」的劇本化教學遭遇（潮翼）。
- 優先級：P1　驗收：正常通關 0 場隨機戰。

## 5. 頭目戰
- 現況問題：不存在。只有同一套野生迴靈戰。
- 玩家感受：沒有高潮。
- 根本原因：無 Boss 專屬規則與演出。
- 改善方式：磁殼仔失衡體，兩階段 60–90 秒：P1 判讀前兆（防禦／干擾對時機）、
  P2 純攻擊不能結束，需在「訊號紊亂」窗口啟動共鳴；前段可選觀測給明示前兆。
- 優先級：P0　驗收：3–5 個有效回合、兩階段視聽差異、攻擊打不死、共鳴收尾。

## 6. 結局
- 現況問題：不存在。戰鬥完就回地圖。
- 玩家感受：「然後呢？」
- 根本原因：無關卡結構。
- 改善方式：共鳴成功→港口聲音回歸演出（鐘聲/村民/色彩變化）→取得「穩定回聲」→
  自動存檔→「第一章：失聲的港灣 完成」→10 秒遠方訊號伏筆→繼續探索/返回標題。
- 優先級：P0　驗收：完成畫面＋伏筆＋Continue 能恢復完成狀態。

## 7. 對話與立繪
- 現況問題：只有地圖小人＋名牌文字框；情緒全靠文字。
- 玩家感受：角色沒有臉。
- 根本原因：無立繪系統。
- 改善方式：40×48 胸像立繪（玩家×5 表情、芮姊×4、阿海伯×4），左右位、說話者高亮、
  進場滑入、可跳過（長按取消）。
- 優先級：P2　驗收：三角色立繪＋表情切換實際在對話中出現。

## 8. 戰鬥手感
- 現況問題：已有前搖/閃白/震動，但敵人行動無前兆、指令仍是傷害數字差異。
- 玩家感受：按攻擊等結果。
- 根本原因：規則層無 telegraph。
- 改善方式：敵人行動前兆（姿勢幀＋文字）；Boss 加防禦/干擾/共鳴的時機決策；
  一般戰敵人攻擊前切 anticipation 幀。
- 優先級：P1　驗收：前三回合內存在「看前兆選反應」的決策。

## 9. 音樂音效
- 現況問題：14 類 SFX 但零環境音、零音樂；「失聲的港灣」卻從頭到尾都沒聲音敘事。
- 玩家感受：世界安靜得像 bug。
- 根本原因：無 ambience/music 系統。
- 改善方式：程序化環境音狀態機（村：海風浪聲**缺鐘聲**→完成後鐘聲回歸；觀測模式收窄；
  古道風聲被干擾；觀測站脈衝；Boss 兩階段配樂加層）＋新 SFX（觀測/線索/共鳴/階段/完成）。
- 優先級：P1　驗收：六種聲音狀態可辨、結局鐘聲回歸。

## 10. 存檔
- 現況問題：v2 完好，但無線索/完成狀態/輔助設定欄位；無自動存檔。
- 改善方式：Schema v3（觀測線索旗標、關卡完成、reduce_flash/shake）＋結局自動存檔＋
  Continue 恢復完成後世界（鐘聲、色溫、對話變體）。
- 優先級：P1　驗收：通關→重新整理→Continue→港口仍是「恢復後」狀態。

## 11. 觸控
- 現況問題：無觀測鍵；戰鬥選單被 A/B 鈕部分遮擋。
- 改善方式：新增觀測觸控鍵；Boss 選單改直式清單避開按鍵區。
- 優先級：P2　驗收：觸控可完整通關（含觀測與 Boss）。

## 12. Web 效能
- 現況問題：良好（single-thread、pck 3MB）；新增粒子/環境音需複測。
- 優先級：P3　驗收：Console 無阻斷錯誤、體感流暢。
