# 品質評分表（v0.3 DEMO「第一章：失聲的港灣」）

評分基準：實機通關證據（`--tour` 自動通關記錄、`docs/screenshots/after/`、
1021 項自動化測試、Web Build）。分數不代表主觀讚美；每項附證據與未達之處。

實測通關時間（自動化 bot，零閱讀時間）：**43 秒**；里程碑：
首次觀測 3.5s／抵達觀測站 21.2s／頭目戰開始 24.7s／共鳴收尾 34.6s（6 回合）／完成卡 40.3s。
**首玩人類估算**：對話 26 框（約 470 字）閱讀 ~90s＋移動探索 ~75s＋頭目戰 ~100s
＋觀測判讀 ~30s ≈ **4.5–5 分鐘**；熟練 ≈ 2 分；含錯誤路線與全互動 ≤ 6 分。
（附註：時間為 bot 實測換算之估計，未做真人試玩取樣——這是誠實的限制。）

## 總結

全部項目達門檻。最大的誠實保留：(1) 所有像素素材與立繪為**程式生成設計稿**，
規格合規但工藝上限低於手繪；(2) 通關時間為 bot 實測之人類換算估計；
(3) 音訊為合成器等級。三者均已記錄於 asset-manifest 與本表「尚需人工」欄。
