# 美術風格聖經 — 潮霧群島

方向一句話：**精緻現代 16-bit Pixel Art × 亞熱帶島嶼的潮濕空氣 × 被自然接管的復古觀測科技。**

品質基準不是 Game Boy，也不是預設素材包；參考的是現代獨立像素遊戲的
場景完成度：清楚的剪影、精準的有限色盤、有層次但不凌亂的細節、
每個畫面都有前景／中景／背景，地圖本身能講故事。

---

## 1. 視覺規格（硬性）

```text
Internal Resolution : 320 × 180（integer scaling）
Base Tile           : 16 × 16
Character Footprint : 16 × 16（碰撞與格座標）
Character Visual    : 16 × 24（頭部越出上格，腳底貼齊格底）
Battle Creature     : 64 × 64 畫布
Filtering           : Nearest（全專案強制）
Mipmaps             : Disabled
Pixel Snap          : 移動座標一律取整數
Global Palette      : 40 色（docs/palette.md，禁止色盤外顏色）
```

## 2. 色彩規則

- 最深色是 **INK #131c26（深藍黑）**，全專案禁止純黑 #000000、純白 #ffffff。
- 環境主色：霧青（MIST 系）、海藍（SEA 系）、苔綠（MOSS/LEAF 系）。
- 聚落重點色：暖黃（AMBER 系）、磚紅（BRICK 系）、珊瑚橘（CORAL，同時是 UI 焦點色）。
- 禁止高飽和 RGB 原色；禁止 3×3 tile 以上的無紋理單色區。
- **每種材質固定三階**：亮面／中間色／陰影，取自同一色系的相鄰三色。
- 同一材質內禁止冷暖色溫互撞（例：磚牆陰影用 BRICK_DK，不用藍系）。
- 漸層一律用兩色棋盤 dither，不用平滑漸層。

## 3. 光影規則

- 全域光源：**上方偏左**。所有 tile／角色／迴靈的亮面在左上、陰影在右下。
- 立物（樹、人、電線桿、迴靈）腳下必須有接觸陰影（INK 20–35% 透明橢圓）。
- 建築南面（面向玩家）比屋頂暗半階；屋簷下加 1px INK 陰影線。
- 室內：暖色光（AMBER 系）為主，窗邊混入冷色（MIST 系），呈現內外色溫差。

## 4. Tile 規則

- 地面 tile 至少 2–3 個紋理變體，鋪設時交錯使用，破除重複感。
- 路徑與草地交界處，路面 tile 內建不規則草緣，禁止直線硬切。
- 水面／高草／海岸泡沫／旗幟為動畫 tile（2–4 幀，8–5 fps）。
- 場景分三層：地面層 → 物件層（含碰撞）→ 頂層（樹冠、電線，蓋過角色）。

## 5. 角色規則

- 玩家與 NPC 皆 16×24；剪影塗黑後必須能互相區分（身形、帽子、道具包）。
- 走路每方向 4 幀（接觸—抬升—接觸—抬升），手腳異相擺動，
  禁止左右幀鏡射了事；頭部與工具包有 1px 縱向慣性。
- 每角色一張 96×96 表：6 欄（idle、走1–4、替代姿勢）× 4 列（下、上、左、右）。
- 玩家替代姿勢列＝互動／接收／戰鬥進場三用的收攏姿勢。

## 6. 迴靈規則

- 剪影測試：塗黑後仍能說出棲地（低寬穩＝石牆林緣；輕斜飛＝港口；緊湊不對稱＝廢棄設備）。
- 不依賴文字辨識屬性：苔角獸帶苔蘚紋、潮翼帶波浪缺刻、磁殼仔帶天線鬚。
- 必備素材：World Icon 32×32、Front 64×64（Idle 2 幀）、Back 64×64、
  Hit 幀（FOAM 白剪影）、Capture Icon 16×16、Status（屬性）Icon 12×12。
- 是生物，不是「物件加眼睛」：要有重心、體積感、至少一處生態細節。

## 7. UI 規則

方向：**復古觀測儀器 × 潮霧群島手冊 × 現代清晰度**（詳見 docs/ui-system.md）。
紙面米白底、深藍綠框線、珊瑚橘焦點；字型 Fusion Pixel 12px（繁中，關閉 AA）。

## 8. 特效規則

- 閃白、震動、粒子全部克制：震動 ≤3px、閃白 ≤0.12s、粒子用色盤色的 1–2px 方塊。
- 特效不得引入色盤外顏色與平滑透明漸層（透明度允許 20/35/60% 三檔）。

## 9. 禁止清單

純色矩形／圓形當素材、Godot 預設外觀、無陰影色塊、文字按鈕、
火柴人、混合像素密度、混合透視、Emoji 圖示、Debug Label 當 UI。
程式生成素材必須遵守以上全部規則，否則視為未完成。
