# 潮森群島 世界設定書（World Bible）

版本：v0.4（御三家認養重製）。本書取代舊版「潮霧群島／回聲觀測」設定；
舊設定之名詞（回聲、觀測員、迴靈、共鳴）不得再出現於任何玩家可見內容。

## 1. 世界

**潮森群島 Tidegrove Isles** 由多座氣候與生態完全不同的島嶼構成：
有霧杉覆嶺的林島、黑沙與地熱的火山島、潮池星羅的環礁，
也有人類聚居的港鎮小島。島與島之間靠定期航班往來，
每座碼頭的公告板是群島的佈告網。

## 2. 伴獸

島上生活著稱為「**伴獸**」的原創生物，是群島自然生態的一部分：

- 有些生活於森林，有些棲息於海岸，有些適應火山與地熱。
- 有些與人類共同生活；有些可以成為旅行夥伴；
  有些必須維持野生狀態（受法規與照護倫理保護）。

**人類與伴獸不是主人與工具的關係。** 正式成為旅行夥伴之前必須完成：
接觸 → 觀察 → **雙向選擇** → 登記認養 → 基本照護訓練。
伴獸可以拒絕人類；認養是牠也選了你。

### 旅伴牌

正式認養後，伴獸配戴「**旅伴牌**」：木材、陶片與金屬構成的小識別牌，
記錄認養人與照護狀態，戰鬥開始時發出簡短光紋，並作為隊伍／存檔 UI 的符號。
旅伴牌**不能**收納伴獸、不能投擲、不發射任何捕捉光線；
伴獸平時直接跟隨旅人行走。

## 3. 玩家（主角定案設定）

剛取得旅行資格的 15 歲島嶼旅人。開朗、好奇、可靠，不過度熱血。
目標不是拯救世界，也不是成為冠軍——第一個目標很簡單：
**認養第一隻伴獸，與牠平安通過離村考驗，正式踏上群島旅程。**

## 4. 第一章舞台：潮芽伴獸之家

海港小鎮邊緣的伴獸認養與照護中心。面向海灣的認養庭院、
半開放木造建築（洗石子牆＋鐵皮屋頂）、三個生態活動區：

- **葉堆培育區**（西）：草木與蕨葉，芽翼鼯的角落。
- **暖石台**（中）：溫暖的石燈平台，燼角羌的地盤。
- **淺水池**（東）：踩水用的淺池，潮冠鷺的遊樂場。

木製認養台、認養證書、牽繩毛刷食盆與旅行包一應俱全。
南側是港口道與棧橋，遠方能看見起航的船。

### 認養師 葵姨

潮芽伴獸之家的管理者。熟悉伴獸行為，語氣直接但溫暖；
不朗讀世界觀、不替玩家決定、不推銷「最強的」。
開場只說兩句：「別急著挑最強的。」「先看看，哪一隻願意跟你走。」

## 5. 御三家

屬性維持經典循環：**草克水、水克火、火克草**。

| | 芽翼鼯（草） | 燼角羌（火） | 潮冠鷺（水） |
|---|---|---|---|
| 生物原型 | 亞熱帶飛鼠×嫩葉×種子 | 山羌×木炭×地熱火種 | 幼鷺×潮汐×水滴 |
| 剪影 | 圓身＋葉形滑翔膜＋種子尾 | 細腿＋兩枚炭黑短角（角縫橙光） | 輕身長腳＋向後捲的浪形羽冠 |
| 性格 | 謹慎：躲在葉後觀察你 | 好勝：轉身牠就偷偷跟上 | 好奇：叼走你的認養表 |
| 認養互動 | 蹲低等牠自己過來→交你一顆種子 | 正面站定接住試探撞擊→對你低角 | 用池面倒影引牠→把表還你 |
| 戰鬥定位 | 防守・牽制 | 爆發・破防 | 速度・擾亂 |
| 技能 | 葉拍／纏芽／葉幕 | 熱蹄／燼角衝／暖火 | 潮羽／霧步／回潮 |
| 跟隨個性 | 隔半步慢慢跟、停下時小跳 | 走在你前面、回頭確認 | 四處亂晃再衝回你腳邊 |
| 結尾動畫 | 跳上肩膀展開葉翼 | 角光映亮前路 | 叼走地圖搶先跑出閘門 |

未被選中的兩隻**留在認養之家**，由葵姨照顧，等待下一位合適的旅人——
不消失、不被拋棄。

## 6. 岩背獾（第一章危機）

背著厚重岩甲的中型伴獸，性情溫和、對巨大聲響極度敏感。
港口施工的巨響讓牠恐慌，撞破圍欄衝進幼獸庭院——
牠不是邪惡怪物，背甲上還卡著施工的金屬片。

戰鬥語法：**恐慌值**取代擊倒。可判讀行動＝噴氣（輕）／縮甲（下回合衝撞的前兆）／
驚慌衝撞（重）。恐慌壓到三成以下後，唯一的收尾是「**安撫**」；
玩家不能用最後一擊消滅牠。事後葵姨取下金屬片，牠自行返回山林。

## 7. 語感原則

台灣口語、句短、動詞在前；不堆世界觀名詞。
角色說話各有節奏：葵姨句短而篤定；旁白像蹲在旁邊描述給你聽。
禁止：「回聲／觀測／迴靈／共鳴」等舊設定詞、
任何寶可夢專有名詞、球形捕捉裝置意象。

## 8. 伏筆（第二章鉤子）

港口公告板：一張被雨水暈開的失蹤伴獸啟事，
只看得清**一雙不同顏色的眼睛**。不解釋。
