# 潮森群島 世界設定書（GHAS 宣導版）

版本：v0.5（A00A 內部宣導改版）。
本作是 A00A 部門的 **GitHub Advanced Security（GHAS）導入宣導遊戲**：
GitHub 平台＝遊戲世界，三個安全功能＝御三家，導入流程＝遊戲流程。
表層是完整可玩的怪獸養成 RPG，裡層每一個機制都對應一條宣導訊息。

**用語原則：一律使用 IT 用語，不造原創詞。**
功能就叫功能（Secret Protection／CodeQL／Code Quality）、
威脅就叫漏洞／外洩／技術債、收服就叫登記啟用、危機收尾就叫修復。

## 2. 舊工具退役、防線交接

海岸原本由三套工具看守——**Checkmarx、SonarQube、Mend**。
它們守了多年、擋過很多事，如今分階段退役。
不是它們不好，是防線要整合進同一個平台。
對舊工具，我們說**功成身退**；防線交接，不留空窗。
交接對應：Checkmarx→Code Security（CodeQL）、SonarQube→Code Quality、
Mend→平台內建的 Dependabot 供應鏈掃描；
**Secret Protection 則是舊組合裡沒有的新防線**——這次交接不只補位，還加高了牆。

## 3. 玩家

A00A IT 的一般開發者。今天輪到你的團隊試點 GHAS——
到前哨站與三隻小獸互動、完成第一次導入、處理第一起外洩事件，
然後帶著夥伴走向還沒有防護的舊程式碼海岸。

## 4. 御三家 ＝ 三個功能

三隻小獸是三個功能的**代表角色**（吉祥物）——**設定直接長在功能上**，
每隻的生物習性就是那個功能在做的事。

| | 鎖鱗甲（草・穿山甲） | 啄錯鳥（火・啄木鳥） | 理木狸（水・河狸） |
|---|---|---|---|
| 功能 | **Secret Protection** | **Code Security**（CodeQL） | **Code Quality** |
| 習性＝功能 | 鱗甲護身、受驚蜷球——秘密鎖進去誰也撬不開 | 專啄木頭最深處的蟲——bug 藏再深都揪出來 | 亂枝理成穩固水壩——重構與可維護 |
| 剪影 | 圓身鱗甲斗篷＋粗尾＋胸口鑰匙孔紋 | 直立黑鳥＋火紅冠羽（掃描光）＋鑿子喙 | 厚實棕身＋格紋大尾＋大門牙 |
| 性格 | 謹慎——鱗甲不為急著伸手的人打開 | 好勝——愛找碴是它愛你程式碼的方式 | 較真——亂的東西它看不下去 |
| 導入互動 | 蹲低掌心朝上，它交出鑰匙鱗 | 伸手臂接受它啄三下（接住掃描報告） | 擺一堆亂枝，它忍不住理好，還你有啃痕的 PR |
| 戰鬥技能 | 鱗甲拍／藤蔓鎖／**推送攔阻**(盾) | 連啄／**深度掃描**(破防)／紅羽預警 | 拍尾水花／潛游／**重構**(淨化) |
| 宣導訊息 | 事前攔一次，勝過事後救一週的火 | 被揪出問題＝被認可，掃描報告要接住 | 乾淨的程式碼照得出倒影 |

**三隻都能導入**：一隻一隻來，三個功能都開，防護才完整。

**導入顧問・安姐**：資安室派駐前哨站的導入輔導顧問（資「安」的安）。
發導入工具包、教事件應變三原則：先降級、不咎責、最後修復。

## 5. 馱庫龜（第一章事件）＝ 外洩事件應變

**馱著十年舊程式庫（背殼）的老龜**——「庫」就是程式庫的庫。
安穩跑了十年的批次作業；金鑰外洩、警報大作，把它嚇得撞破圍欄驚慌暴走。
戰鬥中的「縮甲」＝縮回龜殼＝老系統一出事就整個封閉起來。

戰鬥語法教的就是事件應變：**事件等級**取代擊倒；可判讀前兆＝alert 分級；
壓到底線後唯一的收尾是「**修復**」＝撤銷外洩 token、輪替、恢復服務。
**打不倒的，只能修復；錯的是外洩，不是它，也不是任何人**（blameless）。

## 6. 對手：老桑

隔壁組的資深工程師（「桑」＝ Sonar 的桑）。
「SonarQube 我用了十年，儀表板都摸出手感了，好好的幹嘛換？」
夥伴剛好剋你的＝老手總有一套說法。敗北後嘴硬認輸：
「……反正舊的都要退役了，我回去挑一個 repo 把新的開開看。只開一個喔！」
——工具遷移現場最真實的那種人：抗拒的不是安全，是換掉用順手的東西。

## 7. 長線結構（規劃）

- 各部門＝各島；點亮一座島＝該部門導入覆蓋率達標。
