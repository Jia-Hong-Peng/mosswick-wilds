## 2. 世界觀：哨獸與蝕

程式碼的海岸會被「**蝕**」侵蝕——漏洞是蝕洞、外洩是蝕縫、技術債是蝕沙。
放著不管，整座島（repo 群）會被蝕成灰色的擱淺地。

**哨獸**是群島原生的守望生物。它們不屬於任何人——
它們選擇願意善待程式碼的團隊，駐守在 repo 上，替人看住蝕。
與哨獸結伴要透過**導入儀式**：互動、雙向選擇、登記、掛上刻著
repo 名字的旅伴牌。三頭御三家哨獸各守一道防線，**三隻都帶上，防護才完整**。

### 三座老塔的退役

海岸原本由三座老燈塔看守——**Checkmarx、SonarQube、Mend**。
它們守了多年、擋過很多蝕，如今分階段熄燈退役。
不是它們不好，是防線要整合進同一座群島（同一個平台）。
對老塔，我們說**功成身退**；防線交接，不留空窗。
交接對應：Checkmarx→Code Security（CodeQL）、SonarQube→Code Quality、
Mend→平台內建的 Dependabot 供應鏈掃描；
**Secret Protection 則是舊組合裡沒有的新防線**——這次交接不只補位，還加高了牆。

## 4. 御三家哨獸 ＝ 三個功能

| | 芽翼鼯（草） | 燼角羌（火） | 潮冠鷺（水） |
|---|---|---|---|
| 防線 | **Secret Protection** | **Code Security**（CodeQL） | **Code Quality** |
| 剪影 | 圓身＋葉形滑翔膜＋鎖種子尾 | 細腿＋炭黑短角（角縫掃描光） | 輕身長腳＋浪形羽冠 |
| 性格 | 謹慎——秘密不交給急著伸手的人 | 好勝——愛找碴是它愛你程式碼的方式 | 好奇——盯上你的 PR 就不放過 |
| 導入互動 | 蹲低等它→它交出上鎖的種子 | 站定接住試探→它對你低角 | 用池面倒影引它→它還你標好記號的 PR |
| 戰鬥定位 | 事前攔阻（葉幕＝Push Protection） | 深掘破防（燼角衝＝挖出漏洞） | 清理整流（回潮＝洗去壞味道） |
| 宣導訊息 | 事前攔一次，勝過事後救一週的火 | 被指出問題＝被認可，掃描報告要接住 | 乾淨的程式碼照得出倒影 |

## 5. 岩背獾（第一章事件）＝ 外洩事件應變

背著厚重老架構的服務獸，安穩跑了十年的批次作業。
金鑰外洩、警報大作，把它嚇得撞破圍欄驚慌暴走。

戰鬥語法教的就是事件應變：**事件等級**取代擊倒；可判讀前兆＝alert 分級；
壓到底線後唯一的收尾是「**安撫**」＝撤銷外洩 token、輪替、恢復服務。
**打不倒的，只能修復；錯的是外洩，不是它，也不是任何人**（blameless）。

## 6. 對手：阿汐

隔壁組的資深工程師。「SonarQube 我用了十年，儀表板都摸出手感了，好好的幹嘛換？」
夥伴剛好剋你的＝老手總有一套說法。敗北後嘴硬認輸：
「……反正舊的都要退役了，我回去挑一個 repo 把新的開開看。只開一個喔！」
——工具遷移現場最真實的那種人：抗拒的不是安全，是換掉用順手的東西。

## 7. 長線結構（規劃）

- 各部門＝各島；點亮一座島的燈塔＝該部門導入覆蓋率達標。
- 舊程式碼海岸的野生蝕獸＝掃描 legacy repo 冒出的 alert。
- 伏筆：**影子系統**——從未登記造冊的神祕 repo，只有人見過它的異色雙瞳。

## 8. 語感原則

台灣口語、句短；功能用真名（Secret Protection／CodeQL／Code Quality），
其餘世界觀全原創。不使用 GitHub 官方視覺資產（Octocat 等）；
不使用任何既有怪獸遊戲的名稱、角色與可辨識設計。
禁止舊版設定詞（回聲／觀測員／迴靈／共鳴）與「工具精靈」這類俗稱——
它們是**哨獸**。
